14 Guidelines
✓ Do
  • •Use blue as primary in light mode, mint in dark — always context-aware
  • •Reserve success color (#10B981) for positive status only — not mint
  • •Use floating labels on all text inputs — never static placeholder-only
  • •Apply spring easing to scale/hover interactions for premium feel
  • •Stagger section reveals at 60ms per element for smooth page entry
  • •Dark text on mint — mint is too light for white text
  • •Keep the 4pt spacing rhythm throughout all layouts
✕ Don't
  • •Fill buttons with gradients — always flat or outline only
  • •Use mint as a success color — it conflicts with brand identity
  • •Use blue as primary in dark mode — contrast drops significantly
  • •Use static placeholder text as the only label — disappears on focus
  • •Use linear easing on spring interactions — it feels mechanical
  • •Place white text on mint surfaces — use dark (#060D1A) instead
  • •Mix arbitrary pixel values outside the spacing scale
